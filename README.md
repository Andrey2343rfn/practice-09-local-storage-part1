# Мої налаштування

Практична робота 9.1 «Робота з SharedPreferences у Flutter». Варіант 1. Менеджер налаштувань користувача.

Автор роботи — Свидан Андрій Андрійович.

## Опис роботи

«Мої налаштування» — вебдодаток на Flutter для керування профілем, виглядом, параметрами сповіщень та улюбленими категоріями. Додаток автоматично записує зміни через SharedPreferences і відновлює їх після перезавантаження сторінки. У Chrome дані зберігаються в локальному сховищі браузера для адреси додатка.

## Реалізовані функції

- [x] Редагування імені, електронної адреси, віку та дати реєстрації.
- [x] Світла, темна й системна теми, розмір шрифту від 12 до 24, українська й англійська мови та компактний режим.
- [x] Збереження параметрів Push, Email, звуку й інтервалу нагадувань у годинах.
- [x] Додавання та видалення категорій. Перевірка порожніх і повторних назв.
- [x] Автозбереження з повідомленням «Збережено».
- [x] Перегляд поточних налаштувань у форматі JSON та скидання до типових значень.
- [x] Відновлення даних після перезавантаження сторінки.

## Запуск у VS Code

Потрібні Flutter SDK і Google Chrome. Відкрий папку проєкту у VS Code. У терміналі цієї папки виконай:

```bash
flutter pub get
flutter run -d chrome --web-port=8080
```

Для перевірки збереження зміни ім’я, тему та категорію. Дочекайся повідомлення «Збережено» й онови сторінку в тому самому вікні Chrome. На macOS натисни Cmd + R, на Windows — Ctrl + R. Після цього натисни «Скинути до типових» і перевір, чи відновилися початкові значення.

## Як працює код

| Файл або компонент | Призначення |
| --- | --- |
| `pubspec.yaml` | Описує проєкт і залежності `shared_preferences` та `flutter_localizations`. |
| `lib/main.dart` | Містить типові значення, запуск додатка, інтерфейс і логіку роботи з даними. |
| `PreferencesManager` | Singleton, який читає, записує та видаляє налаштування за ключем `user_settings_v1`. |
| `SettingsApp` | Показує форму, застосовує зміну теми, мови й тексту та запускає збереження. |

Під час першої зміни `save()` створює запис. Наступні виклики оновлюють його. Метод `read()` читає JSON і доповнює збережені значення типовими. Метод `reset()` видаляє ключ зі сховища. Блоки `try/catch` обробляють помилки читання та запису.

## Труднощі та рішення

Під час швидкого введення тексту виникає кілька асинхронних операцій запису. Метод `queue()` ставить їх у чергу, щоб кожна операція завершилася перед початком наступної. Скидання проходить через ту саму чергу. Це запобігає ситуації, коли попередній запис відновлює щойно видалені дані.
